# Navaxx1

Versión web de prueba de PokeDexTracker: una Pokédex de Pokémon Rojo Fuego / Verde Hoja que registra las capturas con una foto de la pantalla de resumen del juego.

- Datos y sprites de la [PokéAPI](https://pokeapi.co).
- Cámara con marco guía, recorte ajustable y OCR en el navegador ([Tesseract.js](https://tesseract.projectnaptha.com/)).
- Logros, retos diarios y semanales, pase de batalla, posts y perfil.
- Los datos se guardan en el navegador (IndexedDB); se pueden exportar e importar desde el Perfil.

Proyecto no oficial, sin relación con Nintendo ni The Pokémon Company.
